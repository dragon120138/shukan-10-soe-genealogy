# 书刊10 央企来时路从行业部到中央企业

> 干部实用·国企史

## 关于本书

今天的百余家中央企业从哪里来？按行业分篇讲清每家央企的来路：从行业部建制到政企分开的拆分重组，到国资委成立后的归并整合，画出从行业部到中央企业的演变图谱。每篇结构：行业历史底子、重组关键节点（哪年拆分、为何拆、谁并谁）、现状格局（主业、上市平台与行业地位）。核心命题：央企格局不是设计出来的，是行业史的沉积。
